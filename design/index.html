Tally

v1 UI for a local-only screen + camera recorder. Every state of the approved scope, on macOS first, with Windows differences in §11. Spec: DESIGN_SPEC.md.

01

Menu-bar launcher

One popover, one primary action. Settings are rows that show their current value and expand in place. Everything persists, so the steady-state path is: click the tray icon, click Record. The camera bubble previews live on screen whenever the camera is on and the popover is open.

02

Camera bubble

The on-screen bubble is a preview; the engine composites the same image into the video. Hover chrome (grip, zoom, blur, hide) is never captured. Four shapes and four sizes (Loom parity), plus a face-centred zoom Loom doesn't have. Sizes are fixed steps so a viewer sees consistent framing across videos.

03

Countdown

The red frame answers "which screen?" before a single frame is captured. The dim outside the frame is only shown in window mode. The digits, ring and hints are excluded from the video.

04

Control bar

A pill at the bottom-centre of the recorded display, draggable, position remembered. Excluded from capture. Elapsed time first, Stop is the only filled control. Restart and Cancel confirm inline in the bar and pause the recording while the question is shown, so the hesitation never reaches the video. The second press of the same shortcut, or Return, confirms; Esc keeps going.

05

After stop

The file is already on disk when this appears. The name field is focused with the base name selected: type to rename, Return to commit, Esc or × to dismiss. Stays until dismissed — no auto-hide.

06

Recordings window

A list, grouped by day, because names and dates are what you scan. Row actions appear on hover or selection. Return renames, Space opens Quick Look (Mac), ⌘⌫ deletes with undo.

07

First run & permissions

Only Screen Recording is asked for up front. Camera is asked inline the first time the camera switch is turned on. No microphone, no Accessibility. Because builds are unsigned, the install guidance ships in the .dmg window and the Windows installer page.

08

Errors

Rule: never lose footage, say what happened in one line, offer the next action. Mid-recording problems surface in the control bar (not captured), not in system dialogs.

11

Windows differences

Same components. The tray popover opens upward from the notification area, shortcuts read Alt+Shift, "Finder" becomes "File Explorer", window controls move right, no popover arrow. Corner radii follow Windows 11 (8px windows).
