Setup v2

In-context setup: a floating toolbar and a live camera bubble on the real screen, with the desktop cover already applied, so what you see is what records. Replaces the launcher popover. Scenes are drawn at true size (1280×800 pt). Spec: SETUP_V2.md.

01

Setup on the real screen

Click the menu-bar icon (or ⌥⇧R with nothing open records straight away, as today). The toolbar appears bottom-centre of that display, the bubble appears with its tray attached, and the chosen cover is applied immediately. Nothing else opens.

02

Setup toolbar

× · source group (Full screen / Window / Area / Camera only) · camera · system audio · cover · more · Record. The active source shows its label, so icons are never the only cue. No microphone control exists. Record keeps its label and width in every mode, so nothing jumps under the pointer.

03

Bubble and its tray

The tray hangs 8 pt under the bubble while setting up and is gone while recording (the v1 hover HUD takes over). Row 1: zoom with detents at 1.0 / 1.25 / 1.5 / 1.75 / 2.0×. Row 2: camera settings · shape · camera off. Row 3: background. Size: drag the corner handle (snaps S/M/L/XL) or pick it in camera settings. Drawn at true size.

04

Desktop cover picker

The swatch button shows the current cover. Clicking a swatch applies it to the real desktop at once (it is the real cover helper, not a preview). “Show desktop” turns the cover off.

05

More menu

Everything that is set once and rarely touched. System audio is here with its label as well as on the toolbar, because a speaker icon alone is ambiguous.

06

Window picker

Choose Window and the screen becomes the picker: hover lights a window in green, click picks it. Tab / ⇧Tab step through windows front to back, Return picks. The bubble jumps inside the picked window (D4). The cover button is disabled: only the window records.

07

Area picker

Choose Area, drag a rectangle. Handles resize, dragging inside moves it, arrows nudge 1 pt (⇧ 10 pt). The bar above the area shows the output size and aspect presets. The area is remembered per display.

08

Camera only

No screen is recorded. The bubble grows into a centred 16:9 stage that matches the output frame, the desktop dims (it is not in the video), and the tray drops the shape control (the output is always 16:9).

09

From toolbar to control bar

One window, one pill. On Record the setup controls fold away (180 ms), the pill re-centres and becomes the countdown bar, then the v1 control bar at frame 1. Same 56 pt height throughout, so it reads as the same object.

10

Countdown and recording

Green becomes red: the selection edge, the countdown ring and the tag switch to the live colour. The tray disappears; the bubble does not move (it stays where it was in setup; drag it lower during recording if wanted).

11

Keyboard focus

Setup takes keyboard focus when it opens (it is a deliberate mode, not a recording). Initial focus: Record, so Return records. Tab order: toolbar left→right, then the tray, then the bubble. ←/→ move inside the source group and the tray’s segments (roving tabindex: one tab stop per group). Esc closes the open popover, else closes setup.

12

Two displays

Setup opens on the display whose menu-bar icon was clicked. Other displays show a glass “Record this display” target in Full screen mode; clicking it moves the toolbar and bubble there. In Window mode windows on every display are pickable. The cover applies to the recorded display only.

13

Windows

Same toolbar and tray. The toolbar sits 16 pt above the taskbar; shortcuts are spelled out; tray icon left-click opens setup.

14

Camera size in the tray

Size and zoom are two separate controls. Size is how big the bubble is on screen and in the video (S 220 · M 280 · L 340 · XL 400 pt). Zoom is how tightly the camera is cropped inside it. The tray is two rows, like Loom's: row 1 is how big (size presets · zoom), row 2 is how it looks (shape · background · settings · off). Supersedes the 3-row tray in §03.

15

Speaker notes

A script panel docked right under the camera lens, so the eyes stay near the lens while reading. Opened from the toolbar. Editable during setup; read-only and scrolling while recording; editable again while paused. Saved locally. Never in the recording.

16

Compact toolbar

Folded by default: grip · expand · what will record · Record. One click on the chevron unfolds the full toolbar to the right; the chevron and grip never move, so the same click folds it again. The recording bar folds the same way. Phase B sources only (Full screen, Window).
